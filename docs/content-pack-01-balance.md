# Content Pack 01 — balance baseline

**Это не заявка на идеальный баланс** — это playtesting baseline для стресс-теста архетипов,
DSL и Resonance. Числа ниже посчитаны по фактическим данным сида (`prisma/seed.ts`) и по реальным
результатам bot-vs-bot матчей между стартовыми колодами (см. ниже), не по интуиции.

## Mana curve по фракциям (5 карт каждая)

| Фракция      | Кривая стоимостей | Средняя стоимость |
| ------------ | ------------------ | ------------------: |
| SHADOW       | 1, 2, 3, 3, 5       |                2.8 |
| PURIFICATION | 1, 2, 3, 3, 6       |                3.0 |
| BOND         | 1, 2, 3, 3, 5       |                2.8 |
| VEIL         | 1, 2, 3, 3, 5       |                2.8 |
| MYSTERY      | 2, 2, 3, 3, 6       |                3.2 |
| COSMIC       | 1, 2, 3, 4, 8       |                3.6 |
| NEUTRAL (10) | 1, 1, 2, 2, 2, 2, 3, 3, 4, 5 |       2.5 |

Cosmic намеренно самая дорогая в среднем (ramp-архетип должен доигрывать до дорогих карт), Shadow/
Bond/Veil — самые дешёвые (агрессия и ранний темп).

| ------------ | ---------: | --------: | -----------: |
| SHADOW       |          4 |      2.50 |         2.75 |
| PURIFICATION |          3 |      2.67 |         5.00 |
| BOND         |          3 |      2.33 |         5.00 |
| VEIL         |          3 |      3.67 |         3.00 |

Purification и Bond намеренно "толстые" (высокое HP, среднее ATK) — control/sustain должны
переживать урон. Veil самая агрессивная по чистой статистике (ATK > HP), что сочетается с Hidden
(атакует безопасно, редко получает ответный удар).

## Removal / disable

Ни одна карта пака не наносит direct damage выше 3 (Пульс Поддержки: 2, Дет Проклятия/Curse:
0 прямого урона, только disable). Основной "removal" пака — **disable, не damage**:
`ADD_STATUS CURSE` (не может атаковать) и `SILENCE` (не может использовать способности) — это
осознанный выбор, чтобы Purification/Veil ощущались как control/tempo, а не burn.

## Healing

- Точечный heal: 1 (Дитя Весеннего Света) .. 3 (Хранитель Обещания, Свет Очага) за карту.
- Board-wide heal: 2 (Матриарх, Свет Очага@T3+).
- `ON_HEAL`-реактивная Руна Отражённого Света даёт Shield **один раз за матч** — намеренно не
  бесконечный шёлд-генератор.

## Draw

Большинство draw-эффектов — 1 карта (Волна Комментариев, Переход Сцены, Музыкальный Всплеск,
Лорд Звёздного Потока). Код Райдо: Резонанс и Хранитель Серого Тумана — единственные карты пака с
базовым draw 2 (Raido/Legendary редкость соответственно, оправдывает более высокую стоимость).

## Energy generation ("temporary Energy this turn")

- Разовая: Искра Звёздного Потока (+1), Портал Звёздного Потока (+2), Пресейв-Сигнал (+1).
- Постоянная (каждый ход): Руна Звёздного Прилива (+1/ход) — главный ramp-энджин Cosmic.
- Cost reduction (альтернатива прямой Energy): Ученица Звёздных Наследников (-2 следующей Cosmic
  карте), Разведка Двора/Руна Безымянного Двора (-1 следующей Veil карте).

## Token generation

Только у SHADOW: Шёпот Заброшенных (1, +1 при T3+), Хранитель Тлеющих Углей (1 при выходе),
Рунный Страж Эха (1 при **любой** гибели союзника, реактивно). Токен «Эхо-Тень» 1/1 —
некомплектуемый (`isToken`), не занимает место в коллекции/deckbuilder'е.

## Потенциально опасные комбинации

- **Рунный Страж Эха + любой источник массового урона по своим существам** — реактивный ON_DEATH
  triggers на КАЖДУЮ смерть союзника, не только целевую; при массовом размене превращается в
  генератор токенов без ограничения на ход. Не break, но требует наблюдения при будущих паках.
- **Голос Подписчиков + Руна Райдо** одновременно на столе — оба реагируют на ON_PLAY первого
  Персонажа за ход (`ONCE_PER_TURN`), суммарно до +2/+2 первому персонажу каждый ход при T3+
  Резонансе — заметный, но некатастрофический стак двух рун одной категории.
- **Некромант Сумеречного Ордена** возвращает первую (не случайную) подходящую карту из сброса —
  детерминированно, значит billboard-порядок discard пайла имеет значение для построения комбо;
  сейчас это тот же порядок, в котором карты уходили в сброс.

## Presumed archetype counters (подтверждено bot-vs-bot)

Матчи прогнаны напрямую через `@kod-raido/game-engine` (`createMatch`/`beginMatch`/`applyAction` +
реальная `chooseBotAction('NORMAL')` для **обеих** сторон, не PvE-бот из продакшена, а прямой
вызов той же эвристики против самой себя на разных колодах) — реальные стартовые 30-карточные
колоды из сида, не синтетические:

| Матчап                                    | Победитель            | Ход | HP (P1/P2) |
| -------------------------------------------- | ------------------------ | --: | ---------: |
| Shadow Aggro vs Bond Sustain                 | **Shadow Aggro**          |  14 |      6 / 0 |
| Mystery Control vs Cosmic Ramp               | **Cosmic Ramp**           |  21 |     0 / 15 |
| Veil Tempo vs Purification Control           | **Veil Tempo**            |  14 |     30 / 0 |
| Shadow Aggro vs Purification Control         | **Purification Control**  |  14 |     0 / 30 |

Наблюдения:

- **Shadow бьёт Bond, но проигрывает Purification.** Быстрый снежный ком Shadow опережает Bond
  до того, как sustain успевает стабилизироваться — но Curse (не может атаковать) и Cleanse
  Purification напрямую разбирают именно тот механизм (атакующие токены/юниты), на котором
  строится Shadow-снежный ком. Ожидаемый, читаемый counter-relationship.
- **Cosmic обгоняет Mystery в долгую** (ход 21 против типичных 14 у других пар) — ramp окупается
  только в позднем миде/лейте; Mystery не наносит достаточно проактивного давления, чтобы закрыть
  игру раньше, чем Cosmic доберётся до дорогих карт.
- **Veil сминает Purification без потери HP** — чистый темп-blowout: ранний Hidden/Impulse-темп
  наносит урон быстрее, чем Purification успевает развернуть щиты/клинзы. Это самый однобокий
  результат из четырёх и кандидат на пересмотр (например, чуть дешевле `rune-of-curse-breaking`
  или на 1 больше базового HP у `acolyte-of-the-white-rune`) в следующей итерации баланса —
  осознанно не трогалось в этой фазе, чтобы не выйти за рамки playtesting baseline.

## Итог

Кривые стоимостей и статы различаются по фракциям в соответствии с их заявленной ролью (Cosmic
дороже/позже, Shadow/Veil дешевле/быстрее), disable-ориентированный removal вместо burn-урона,
12 из 40 карт реагируют на Resonance без auto-win на любом Tier, и bot-vs-bot результаты дают
читаемые, объяснимые counter-relationships между архетипами — достаточно для playtesting baseline,
но **не** финальная балансировка.
